# Group 8 Formative 2 Principle Component Analysis
This project applies Principal Component Analysis (PCA) to a African development indicators from the World Bank dataset.

### Process
- Cleaned and imputed missing values using country-specific means.
- Standardized the numerical features.
- Computed the covariance matrix, eigenvalues, and eigenvectors using NumPy.
- Reduced the dataset from 10 features to 6 principal components.
- The first 6 components retain approximately 91.53% of the total variance.
- Visualized the original feature space and PCA-reduced data using Matplotlib.

### Tools
- Python
- NumPy
- Matplotlib
